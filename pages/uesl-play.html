OpenCS Workbench

Choose a background, player, NPCs and barriers. Push → generates code; Pull ← reads supported changes back into the setup. Use Run, Pause and Stop above the editor. Save a return point or export a workspace JSON backup from its toolbar.

Open World

The inherited multi-level builder includes maze backgrounds, characters, drawing tools and accessibility settings. Level drafts stay in this browser. Export Code makes a separate copy. Account Save/Load still needs backend support.

Racing

Keep the inherited cars, tracks, weather and performance controls. Run starts a race; Stop returns to the track preview. Garage progress stays in this browser.

Each builder keeps its own format. Switching tabs preserves your open work and stops the preview. Browser saves stay on this device and address; export a backup before clearing browser data.
